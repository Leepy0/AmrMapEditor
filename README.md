# AMR Map Editor v0.4

AMR 맵(PGM) 전용 편집기. GIMP 대체용으로, 신규 맵 정리와 기존 맵 업데이트 보정에 필요한 기능을 담았다.

그림과 단계별 재생이 포함된 사용 안내는 `docs/guide.html`을 브라우저로 여세요.

## 빌드 / 실행

- .NET 10 SDK, Windows
- Visual Studio: `AmrMapEditor.slnx` 열고 실행
- CLI: `dotnet run --project src/AmrMapEditor`
- 외부 NuGet 패키지 없음 (순수 C# 구현)

pgm 파일을 창에 끌어놓거나 `Ctrl+O`로 연다. exe 인자로 경로를 넘겨도 된다.
같은 폴더에 같은 이름의 `.yaml`(또는 image 항목이 이 파일인 yaml)이 있으면 resolution/origin을 읽는다.

## 픽셀 값 규칙

| 값 | 의미 | 표준 표시 |
|---|---|---|
| 0 (0x00) | Unknown | 청회색 |
| 1 (0x01) | Free | 흰색 |
| 254 (0xFE) | 장애물 | 검정 |
| 2 ~ 253 | 확률 (클수록 장애물 쪽으로 가정) | 회색 그라데이션 |
| 255 | 범위 외 → 경고 | 마젠타 |

- 값 입력칸은 `254`, `0xFE`, `FEFEFE`, `#FEFEFE` 형식을 모두 받는다.
- "장애물 기준값"(편집 탭 › 맵 설정, 기본 128 이상)은 노이즈 검출, 기준 맵 비교, 벽·기둥 정리에 공통으로 쓴다.

## 화면 구성

Apple 디자인 언어(macOS 인스펙터)를 기준으로 글자를 줄이고 아이콘과 카드 위주로 구성했다.

- **상단 도구 막대**: 같은 크기(32 px)의 아이콘 버튼. 왼쪽 파일 · 실행 취소, 가운데 표시 방식(표준 · 확률 · 분류 · 원본), 오른쪽 픽셀 격자 · 화면 맞춤 · 단축키 도움말(?). 마우스를 올리면 이름과 단축키가 나온다.
- **왼쪽 도구**: 아이콘만 있는 도구 막대. 선택한 도구는 파란색으로 채워진다. 맨 아래 색 칩이 현재 그리기 값이다.
- **오른쪽 인스펙터**: 세그먼트 탭 4개
  - **편집**: 열린 맵, 그리기 값, 브러시, 선택 영역, 보호 영역, 맵 설정(해상도 · 장애물 기준값 · 변경 이력)
  - **업데이트**: 기준 맵을 열면 단계 카드(2~6)가 나타난다. 끝난 단계는 번호가 초록 체크로 바뀐다.
  - **정리**: 노이즈 제거, 벽 끊김 잇기, 벽 · 기둥 반듯하게, 확률값, 외곽, 기울기 보정
  - **도면**: DXF 오버레이와 정렬
- **작업 대상 막대**: 탭 바로 아래에 지금 대상이 "맵 전체"인지 "선택 영역"인지 표시한다. 선택 영역이 있으면 편집 · 후보 찾기 · 정리는 그 안에서만 실행된다. ✕로 선택을 해제한다.
- 세부 설명은 제목 옆 ⓘ에 마우스를 올리면 보이고, 자주 바꾸지 않는 값은 각 카드의 **옵션** 안에 접혀 있다.
- 선택 영역이 필요한 버튼(외곽 정리, 선택 영역 직선화 등)은 선택 영역이 없으면 비활성화된다.

## 도구 / 단축키

| 키 | 도구 | 동작 |
|---|---|---|
| B | 브러시 | 선택한 값으로 칠함 |
| E | 지우개 | Free(1)로 칠함 |
| L | 직선 | 드래그, Shift = 0/45/90° 스냅 |
| R | 사각형 | 드래그, "사각형 속 채우기" 옵션 |
| G | 채우기 | 같은 값으로 연결된 영역(4방향) |
| I | 스포이드 | 클릭한 값을 그리기 값으로 |
| M | 영역 선택 | 드래그, 클릭 = 해제 |
| P | 폴리곤 선택 | 클릭 = 꼭짓점, 더블클릭/Enter = 완료, Backspace = 되돌리기 |
| D | 객체 삭제 | 클릭한 장애물 덩어리(8방향 연결) 전체를 Free로 |
| H | 복원 브러시 | 칠한 부분을 기준 맵 값으로 되돌림 |
| W | 벽 직선화 | 벽 하나를 감싸듯 드래그 → 직선으로 다시 그림 |
| C | 기둥 정리 | 클릭한 덩어리를 사각형으로 |

| 키 | 기능 |
|---|---|
| 휠 | 확대/축소 (커서 기준) |
| 가운데 버튼 드래그, Space + 드래그 | 화면 이동 |
| F | 화면 맞춤 |
| [ / ] | 브러시 크기 |
| 1 / 2 / 3 | 그리기 값 Free / 장애물 / Unknown |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 (최대 100단계) |
| Ctrl+D, Esc | 선택 해제 (Esc는 진행 중인 드래그·폴리곤·정렬 취소가 우선) |
| Ctrl+O / Ctrl+S / Ctrl+Shift+S | 열기 / 저장 / 다른 이름으로 저장 |

- 선택 영역이 있고 편집 탭의 "선택 영역 안에서만 편집"이 켜져 있으면, 브러시 같은 일반 편집은 선택 영역 밖에 적용되지 않는다.
- 노이즈 · 벽 끊김 후보 찾기와 확률값 정리는 선택 영역이 있으면 그 안에서, 없으면 맵 전체에서 실행한다.
- 영역 밖 복원, 외곽 정리처럼 범위를 스스로 정하는 기능은 이 설정의 영향을 받지 않는다.
- 줌 1200% 이상에서 픽셀 격자를 표시한다.

## 작업 흐름

### A. 업데이트 보정 (기존 맵에 업데이트가 덧그려진 경우)

업데이트된 맵을 열고 **업데이트** 탭을 위에서부터 진행한다. 끝난 단계는 번호가 초록 체크로 바뀐다.

1. **기준 맵**: 업데이트 전 맵을 연다.
   - 두 맵 모두 yaml이 있으면 origin 기준으로 자동 정렬한다. 크기가 달라도 비교할 수 있다.
   - 변경점 색상: 빨강 = 새로 생긴 장애물, 파랑 = 사라진 장애물, 노랑 = 기타 값 변화
2. **업데이트 영역**: 이번에 실제로 다시 스캔한 범위를 사각형이나 폴리곤으로 선택해 추가한다. 여러 개를 추가할 수 있다.
3. **영역 밖 변경 복원**: 업데이트 영역 밖에서 달라진 픽셀을 모두 기준 맵 값으로 되돌린다.
4. **어긋남 확인 / 재정렬**
   - 새로 생긴 장애물을 기존 벽에 맞춰보고 dx, dy, 회전을 추정한다.
   - 일정하게 수 px 밀려 있으면 업데이트 당시 위치 인식이 틀어진 것이다.
   - "옮겨서 합치기"는 업데이트 내용을 추정한 만큼 옮겨 기존 맵에 다시 합친다. 정수 px 이동만 적용한다.
   - 회전 어긋남이 크면 편집으로 맞추기보다 업데이트를 다시 하는 편이 맞다.
5. **이중 벽 정리**
   - 새로 생긴 장애물 중 기존 벽 바로 옆(기본 10 px 이내)에 붙은 덩어리를 후보로 보여준다.
   - 체크한 항목을 기준 맵 값으로 복원한다. 기존 벽을 남기는 것이 기본이다.
   - 기존 벽 옆에 새로 설치한 설비도 후보로 잡히므로 확인한 뒤 복원한다.
6. **변경 영역 확인**: 남은 변경을 목록으로 하나씩 확인한다. 부분 수정은 복원 브러시(H)로 한다.
7. **마무리**: 정리 탭에서 노이즈를 제거한 뒤 저장한다 (업데이트 탭 맨 아래 "마무리: 노이즈 정리"). 저장 확인창에 기준 맵 대비 변경량과 영역 밖 변경이 다시 표시된다.

### B. 신규 맵 정리

1. **노이즈 객체 제거**
   - 면적·크기 조건으로 캐스터 같은 작은 덩어리를 검출하고, 확인한 뒤 일괄 삭제한다.
   - 하나씩 지울 때는 객체 삭제 도구(D)를 쓴다. 500 px가 넘는 덩어리는 벽일 수 있어 확인창이 뜬다.
2. **기울기 보정**: 맵이 건물 축과 틀어져 있으면 정리 탭 맨 아래 기능으로 벽을 수평·수직에 맞춘다. 주의사항은 아래에 따로 적었다.
3. **벽 직선화 (W)**
   - 드래그한 영역 안의 장애물을 벽 단위로 나눠 각각 직선에 맞춰 지정 두께로 다시 그린다.
   - 영역 안에 벽이 여러 개(평행한 두 벽, 서로 다른 각도의 벽 등) 있어도 따로 인식해 처리한다.
   - 같은 벽 안에서 몇 px 이내로 끊긴 구간은 하나로 이어서 그리고, 그보다 멀리 떨어진 덩어리는 별개의 벽으로 본다.
   - 두께 0이면 벽마다 원래 두께를 추정해 쓴다.
   - 맵 주축 근처 각도(±3°)는 벽마다 주축에 스냅한다.
4. **기둥 정리 (C)**
   - 기둥을 클릭하면 덩어리를 감싸는 사각형으로 바꾼다.
   - 한두 면만 스캔된 L자 형태도 사각형이 된다.
   - "속 채우기"를 끄면 테두리만 그린다.
5. **벽 끊김 후보**
   - 유리나 반사면 때문에 끊긴 벽을 찾는다.
   - 수평·수직 벽만 대상이므로 기울어진 맵은 기울기 보정을 먼저 한다.
   - 출입구도 후보가 될 수 있어서 기본은 체크 해제 상태다.
6. **외곽 정리**: 건물 외곽을 폴리곤(P)으로 선택하고 "선택 영역 밖을 Unknown으로"를 실행하면, 창문 너머로 찍힌 산란점이 정리된다.
7. **확률값 정리**: 지정한 값 이하는 Free, 장애물 기준값 이상은 장애물로 바꾸고 그 사이 값은 유지한다.

**기울기 보정 주의사항**
- 맵 크기와 좌표계가 바뀐다. 스테이션·경로 티칭 전의 신규 맵에만 쓴다.
- 기준 맵 비교 중에는 실행되지 않는다.
- 실행 취소 이력이 초기화된다. 저장 전이라면 파일을 다시 열어 되돌릴 수 있다.
- 보호 영역과 도면 배치는 함께 회전한다.
- 저장할 때 yaml origin을 갱신한다.
- 회전은 Nearest neighbor 방식이라 벽에 계단 모양이 생길 수 있다. 벽 직선화로 정리한다.

### C. 보호 영역

- 충전·도킹 스테이션, 반사판, 고정 기둥처럼 지우면 안 되는 곳을 선택한 뒤 "선택 영역을 보호"로 추가한다.
- 모든 편집(브러시, 노이즈 제거, 복원, 외곽 정리 등)에서 보호 영역은 바뀌지 않는다.
- 보호 영역에 걸친 후보는 목록에서 빠진다.
- `<맵>.pgm.protect.json`에 저장되며, 다음에 맵을 열면 자동으로 불러온다.

### D. 도면 (DXF)

1. 도면을 열면 맵 중앙에 배치된다. 단위는 `$INSUNITS`를 따르고, 미지정이면 mm로 가정한다.
2. 레이어 목록에서 벽·기둥만 남기고 나머지는 숨긴다.
3. "2점 정렬 시작"을 누른 뒤 다음 순서로 클릭한다.
   1. 도면 점 A
   2. 맵에서 A와 같은 위치
   3. 도면 점 B
   4. 맵에서 B와 같은 위치
   - 도면 점은 가까운 꼭짓점에 붙는다.
   - 축척 고정(기본)이면 회전·이동만 맞추고, 두 점의 오차를 표시한다.
4. 세부 조정은 이동/회전/축척 값을 직접 입력한 뒤 "값 적용"을 누른다.
5. 정렬 결과와 숨긴 레이어는 `<맵>.pgm.dxf.json`에 저장되어, 맵을 다시 열면 자동으로 적용된다.

지원 엔티티는 LINE, LWPOLYLINE(bulge 포함), POLYLINE, CIRCLE, ARC, INSERT(블록 전개)다. 텍스트·해치·치수는 무시한다. ASCII DXF만 지원하며 인코딩은 UTF-8/CP949를 자동 판별한다.

## 저장

저장 전 확인창에서 다음을 보여준다.
- 값별 픽셀 수, 255 개수
- 열었을 때 대비 변경량
- 기준 맵 대비 변경량, 업데이트 영역 밖 변경
- 크기 변경 경고

저장할 때 함께 처리되는 것:
- **백업**: 기존 파일은 `<맵 폴더>/_backup/<이름>_yyyyMMdd_HHmmss.pgm`에 백업한다. 임시 파일에 쓴 뒤 교체하므로 저장 중 오류가 나도 원본이 유지된다.
- **변경 이력**(끌 수 있음): `<맵 폴더>/_history/`에 diff PNG(빨강 추가·파랑 삭제·노랑 기타)와 작업 목록 txt를 남기고, `history.log`에 한 줄씩 누적한다.
- **yaml**
  - 같은 이름으로 저장하면 origin이 바뀐 경우에만 갱신한다.
  - 다른 이름으로 저장하면 새 이름의 yaml을 만들고 image 항목을 교체한다.
  - 덮어쓰는 yaml도 `_backup`에 백업한다.
- **형식 보존**: 헤더 주석, 형식(P5/P2), maxval을 그대로 유지한다.
- **입력값 기억**: 장애물 기준값, 노이즈 조건 등은 `%AppData%\AmrMapEditor\settings.json`에 저장되어 다음 실행 때 유지된다.

## 샘플

`samples/` 폴더:

| 파일 | 내용 | 확인할 기능 |
|---|---|---|
| sample_before.pgm | 기준 맵 (업데이트 전) | |
| sample_updated.pgm | (+3, +4) px 어긋난 이중 벽 2개, 신규 랙 1개, 캐스터 20개, 영역 밖 변경 | 업데이트 탭 |
| sample_new.pgm | 4° 기울어진 신규 맵: 톱니 벽, 유리·반사면 끊김, 출입구, L자 기둥, 외곽 산란점 | 정리 탭 |

업데이트 보정 예시:
1. `sample_updated.pgm`을 열고 기준 맵으로 `sample_before.pgm`을 연다.
2. 업데이트 영역으로 대략 (30, 120) ~ (370, 270)을 선택해 추가한다.
3. 3단계(영역 밖 복원) → 4단계(어긋남 추정: dx −3, dy −4) → 5단계(이중 벽 복원) → 정리 탭에서 노이즈 제거 순으로 진행한다.
4. 끝나면 기준 맵 대비 신규 랙만 남는다.

## 제한 사항

- 업데이트분 재정렬은 정수 px 이동만 적용한다. 회전 추정값은 진단용이다.
- 벽 끊김 자동 검출은 수평·수직 벽만 대상이다. 기울어진 벽은 벽 직선화(W)로 영역을 잡아 이어 그린다.
- 크기가 다른 기준 맵은 yaml origin이 있어야 정확히 정렬된다. yaml이 없으면 왼쪽 아래 기준으로 맞춘다.
- 해상도가 다른 맵끼리는 비교할 수 없다.
- 8bit PGM만 지원한다 (16bit 미지원).
- yaml의 origin 회전(theta)은 좌표 표시에 반영하지 않는다.
