AMR Map Editor

AMR 맵(PGM)을 GIMP 대신 정리하는 전용 편집기입니다. 업데이트로 겹쳐 그려진 벽, 대차 캐스터 같은 작은 노이즈, 거칠게 찍힌 벽과 기둥을 맵 값 규칙에 맞춰 정리하고, 나눠 그린 맵을 이어 붙여 큰 맵을 만듭니다.

업데이트 직후 보정 후

샘플 맵 비교입니다. 가운데 손잡이를 좌우로 끌면 겹쳐 그려진 벽과 흩어진 캐스터가 정리된 결과를 볼 수 있습니다.

맵 값 규칙

편집기는 이 규칙으로 맵을 읽고 씁니다. GIMP에서는 Unknown(0)과 Free(1)가 둘 다 검게 보이지만, 편집기의 표준 표시에서는 색으로 구분됩니다.

0 · Unknown스캔되지 않은 곳
1 · Free지나갈 수 있는 곳
254 · 장애물벽, 기둥, 설비
2 ~ 253 · 확률값이 클수록 장애물 쪽
255 · 범위 밖저장 전에 경고

화면 구성

각 부분을 누르면 설명이 나옵니다. 오른쪽 패널의 탭도 눌러볼 수 있습니다.

sample_updated.pgm — 편집됨 · AMR Map Editor

    실제 창을 단순하게 옮긴 구성도입니다. 가운데 맵은 편집기 엔진이 샘플을 처리한 실제 결과입니다.

    기존 맵에 업데이트가 덧그려졌을 때

    업데이트는 기존 맵 위에 덧그려지므로, 위치 인식이 조금만 틀어져도 벽이 두 겹이 됩니다. 업데이트 탭에서 위에서부터 차례로 진행합니다. 재생을 누르면 단계별로 넘어가며, 후보가 표시된 뒤 적용 결과로 바뀝니다.

    새로 생긴 장애물 사라진 장애물 그 밖의 값 변화 기준 맵의 장애물 업데이트 영역 노이즈 후보

    새로 만든 맵을 정리할 때

    처음 만든 맵은 건물 축과 틀어져 있거나 벽이 계단처럼 거친 경우가 많습니다. 정리 탭의 기능으로 정리하는 과정입니다.

    끊김 후보 직선화 영역 기둥 건물 외곽 노이즈 후보

    나눠 그린 맵을 합치거나 일부만 새로 그렸을 때

    넓은 현장을 여러 번 나눠 그린 맵, 또는 일부만 새로 그린 맵은 크기와 원점이 서로 다릅니다. 맞추기 탭에서 맞출 맵을 대략 끌어다 놓으면 자동 정렬이 회전과 위치를 정확히 맞추고, 합쳐서 큰 맵을 만들거나 기존 맵과 비교해 반영합니다. 현재 맵의 좌표는 그대로 두고 맞출 맵만 움직입니다.

    맞출 맵 장애물 맞출 맵 Free 겹친 같은 벽 새 맵에만 있는 장애물 현재 맵에만 있는 장애물 맞출 맵 범위 (점선)

    도면과 맞춰 보기

    건축 도면(DXF)을 맵 위에 겹쳐 벽과 기둥이 제자리에 있는지 확인합니다. 도면 탭에서 진행합니다.

    지우면 안 되는 곳과 저장

    보호 영역

    충전 스테이션, 반사판, 위치 인식에 쓰이는 고정 기둥처럼 건드리면 안 되는 곳을 녹색 보호 영역으로 지정합니다.

    • 보호 영역은 브러시, 노이즈 제거, 복원, 외곽 정리 등 모든 편집에서 바뀌지 않습니다.
    • 보호 영역에 걸친 후보는 목록에 나타나지 않습니다.
    • 맵 옆 .protect.json 파일에 저장되어, 다음에 맵을 열면 그대로 불러옵니다.

    저장

    평소에는 확인창 없이 저장하고 상태 표시줄에 변경 픽셀 수와 백업 위치를 보여줍니다. 크기 변경, 범위 밖 값(255), 업데이트 영역 밖 변경처럼 확인할 내용이 있을 때만 저장 전에 묻습니다. 확인창의 '자세히'에 값별 픽셀 수와 변경량 요약이 있습니다.

    • 기존 파일은 _backup 폴더에 시각을 붙여 백업합니다.
    • _history 폴더에 위와 같은 변경 이미지와 작업 목록이 남습니다.
    • yaml은 원점이 바뀌었거나(기울기 보정 · 합치기) 새 이름으로 저장할 때만 갱신합니다.
    • 파일 헤더 주석과 형식(P5/P2)은 그대로 유지됩니다.

    시작하기

    • AmrMapEditor.exe를 받아 문서나 바탕화면 같은 폴더에 두고 실행합니다. 설치할 것이 없습니다.
    • 시작할 때 새 버전을 확인해 상태 표시줄에 알려줍니다. 받아 두면 프로그램을 닫을 때 바뀌고, 문제가 있으면 정보(ⓘ) 창에서 이전 버전으로 되돌립니다.
    • 맵은 창에 끌어놓거나 Ctrl+O로 엽니다. 같은 이름의 yaml이 있으면 해상도와 원점을 읽습니다.
    • samples 폴더의 맵으로 이 안내의 과정을 그대로 따라 할 수 있습니다.

    알아둘 점

    • 업데이트분 재정렬은 정수 픽셀 이동만 합니다. 회전 어긋남이 크면 업데이트를 다시 하는 편이 낫습니다.
    • 벽 끊김 자동 검출은 수평·수직 벽만 찾습니다. 기울어진 맵은 기울기 보정을 먼저 합니다.
    • 기울기 보정은 좌표계를 바꾸므로 스테이션을 가르치기 전의 새 맵에만 씁니다.
    • 해상도가 다른 맵끼리는 비교하거나 합칠 수 없고, 8bit PGM만 지원합니다.
    • 기준 맵으로 연 맵의 벽이 현재 맵과 35% 넘게 어긋나면 따로 그린 맵으로 보고 맞추기 탭을 권합니다. 이런 맵으로 영역 밖 되돌리기 · 옮겨서 합치기를 하면 기준 맵 내용이 현재 맵에 덮어써지므로 실행 전에 한 번 더 묻습니다.
    • 실행 취소할 수 있는 작업은 확인창 없이 바로 실행하고, 상태 표시줄의 실행 취소 링크나 Ctrl+Z로 되돌립니다. 확인창은 기울기 보정 · 합치기처럼 되돌릴 수 없는 작업에만 뜨고, 이때 기본 버튼(Enter)은 취소입니다.
    • 도구 막대의 달 아이콘으로 다크 모드를 켭니다. 처음에는 Windows 설정을 따릅니다. 오류가 나면 원인과 해결 방법을 보여주고, 자세한 내용은 %AppData%\AmrMapEditor\error.log에 남깁니다.
